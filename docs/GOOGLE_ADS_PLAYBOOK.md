## Step 3 — Set up call conversion tracking (critical)

Without this, Google cannot optimize for real customers.

### Option A — Website call clicks (easiest start)

1. Google Ads → **Goals → Conversions → Summary → + New conversion action**  
2. Select **Phone calls**  
3. Choose **Calls to a number on your website** (or **Clicks on a number on your website**)  
4. Settings:
   - **Category:** Contact  
   - **Value:** Use same value for each conversion → start with **₹300–₹500** (approx profit per booked job, adjust later)  
   - **Count:** One  
   - **Click-through conversion window:** 7 days  
5. Install the **Google tag + event snippet** on the website (or use Google Tag Manager)  
6. Make sure all call buttons use the tracked number / click-to-call links (`tel:+919606805425`)

### Option B — Calls from ads (Call assets)

1. New conversion → **Phone calls** → **Calls from ads**  
2. Minimum call length: **60 seconds** (filters accidental taps)  
3. Use Google’s **call reporting** number that forwards to **+919606805425**

**Best practice:** Set up **both** A and B.

Mark call conversions as **Primary** so bidding optimizes for them.

## Step 4 — Create the main Search campaign

### 4.1 Campaign setup

1. **+ New campaign**  
2. Goal: **Leads** (or **Create campaign without a goal’s guidance**)  
3. Campaign type: **Search**  
4. Select conversion goals: your **Call** conversions only (uncheck random page views)  
5. Campaign name: `BLR | Search | WM+Fridge Repair | Calls`  
6. Networks: **uncheck** Search Partners and Display Network  
7. Locations:
   - Enter **Bengaluru, Karnataka, India**  
   - Location options → **Presence: People in or regularly in your locations**  
   - Do **not** include “interested in”  
8. Languages: **English** and **Hindi** (optional: Kannada later)  
9. Budget: start **₹700/day** (adjust after 7–14 days)  
10. Bidding:
    - Start: **Maximize clicks** with bid cap **₹25–₹40** for first 5–7 days (collect data)  
    - Then switch to **Maximize conversions** (once 15–30 call conversions exist)  
    - Later: **Target CPA** (e.g. ₹150–₹250 per call if quality is good)

## Step 8 — Ad schedule & devices

### Devices
- Start: **All devices**, but expect **70–85% mobile**  
- After 7 days: if desktop drains budget with few calls, reduce desktop bids by 20–40%

### Ad schedule (Bangalore)
Bid higher when someone can answer:

| Time | Bid adjustment |
|---|---|
| 8:00 AM – 9:00 PM | +0% to +20% |
| 9:00 PM – 8:00 AM | Pause or −80% |

If night calls are never answered, **pause overnight** — don’t pay for missed leads.

## Step 10 — Optimize every week (what actually moves ROI)

### Daily (first 2 weeks)
1. Check **Search terms** → add negatives  
2. Check wasted spend on irrelevant queries  
3. Confirm calls are being recorded as conversions  

### Weekly
1. Pause keywords with spend and **0 calls** after meaningful clicks  
2. Increase bids / budget on ad groups with cheapest qualified calls  
3. Improve RSA: pin 1 strong headline with phone/city if needed  
4. Match landing experience: number visible above the fold (already on site)

### After ~15–30 conversions
Switch bidding from Maximize clicks → **Maximize conversions**  
Then later → **Target CPA**

## Exact keyword themes that convert best for this niche

**Highest intent (bid aggressive):**
- washing machine repair bangalore  
- fridge repair bangalore  
- refrigerator repair near me  
- washing machine repair near me  

**Strong mid intent:**
- brand + repair + bangalore (LG, Samsung, IFB, Whirlpool, Bosch)  
- symptom keywords (not cooling, not spinning, leaking, error code)  

**Usually weaker (careful):**
- generic “appliance service” without city  
- “customer care number” / “official service centre” (wrong intent / complaint seekers)

**Important compliance note:**  
You are an **independent multi-brand** provider. In ads, prefer:

- “Independent multi-brand repair”  
- “We service LG / Samsung models”  

Avoid claiming **“Official / Authorised Service Centre”** unless you legally are.
